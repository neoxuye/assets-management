# Lumi 系统文档中心 (System Documentation Center)

本目录为 Lumi 资产配置系统的核心说明书库，遵循 KISS（保持简单）原则与全局文档规范。

## 目录结构说明

- **[02_Architecture/](./02_Architecture/)** *(核心)*
  系统的灵魂。包含系统架构总纲与顶层心智模型。遇到不懂的机制优先查阅此目录。

- **[03_Reference/](./03_Reference/)**
  日常使用的参考手册汇编。包括产品说明书、数据字典、宏观因子体系以及用户使用指南。

- **[04_Templates/](./04_Templates/)**
  数据生成和自动化注入时需要使用的各类模板（如 CSV, JSON）。
